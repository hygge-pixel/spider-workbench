# v2 导出调整记录

> 历史迁移/实施记录：文中 Cloak 优先、Chrome 兼容模式及两项 MCP 同时接入的旧默认已由当前用户决策替代。当前部署统一按 [INSTALL_WITH_AGENT](INSTALL_WITH_AGENT.md) 和 [Chrome for Testing 工单](CHROME_FOR_TESTING.md)，只启用 chrome/9222 与 js-reverse；本记录不作为当前默认部署指令。

## 范围与源项目

本版在昨晚 v1 的独立副本上补齐工具接入。当前源工作区的 CLI、spider_core、可选后端和离线示例关键文件按字节核对；不修改源工作区已有流程、配置、能力或数据。
旧站点 collector、proof、历史运行、交付数据、凭据、登录态、个人 Agent 设置仍不随包携带。

## 新增

- JSReverser 2.0.3 当前使用源码快照：97 个 src TypeScript 文件、构建所需 package/lock/tsconfig/scripts 和许可证，不携带源码仓库案例/测试/运行材料/node_modules/build。
- SOURCE_SNAPSHOT.json 记录原始源码哈希、来源与分发适配；只为运行目录增加 SPIDER_MCP_RUN_DIR 支持，源码构建后缓存/证据隔离到本项目 runs/_mcp。
- Python 采集工具直接版本声明、pytest、Playwright CLI 独立 lock、隔离安装器和 MCP/Playwright 真连接验收。
- Node 单进程 MCP 启动器及短时 Python 身份预检。避免包装进程退出后遗留后台 MCP 子进程。
- 三方哈希升级器、冲突保护、显式接受已人工合并文件、重复执行与回滚保护。
- 可单独发送的旧版调整工单，以及新的首次部署/工具链/分层验收文档。

## 与旧包的区别

v1 只交付核心离线框架和可选接入原则；v2 把 JSReverser/Playwright/Python/Node 作为完整框架部署的基础工具层。日常任务仍按证据使用这些工具，不强制每次走浏览器，不自动注册，不自动安装全部专项 MCP。
源环境的本机程序绝对路径和登录态不迁移，改由目标机发现/生成。Cloak 本体不是公开源码依赖，本包不擅自分发其二进制；缺少时明确记录 Chrome 兼容模式。
新包初始空表仅适用于新部署。升级器始终保护目标平台注册表、已有任务、运行/输出、Profile、本机实际配置，不拿空表覆盖。

## 验证边界

包外验证报告记录实际 fresh install/build、两项空 Profile、MCP 初始化/只读调用、Playwright 合成页面、框架回归和旧包升级模拟结果。
临时验收 Profile 为静默 headless；源工作区日常默认不因此改为 headless。Cloak 的合成检查使用 data URL 和 DOMContentLoaded，避免其 set_content/load 生命周期差异。
目标电脑和目标 Agent 仍须现场验收。CLI 探针不等于宿主工具已加载；工具安装/测试不等于真实网站业务成功。Windows 核验结果不能外推 macOS/Linux 的进程身份实现。
ZIP/manifest 是传输完整性检查，不是第三方认证签名。Python 仅锁直接版本，npm 使用传递依赖 lock；不宣称所有操作系统环境逐字节一致。
