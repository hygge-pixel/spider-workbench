# 公开源码整理方案与实施记录

目标：从可审阅的干净框架快照建立独立 GitHub 源码包，不直接发布私有工作区或原 Git 历史。用户选择按推荐方案连续完成。

方案比较：全工作区清洗保留案例维护/泄露成本高；仅文档模板缺可运行工具层；选择完整纯框架+工具链，保留核心和13 Skills，排除历史能力和数据。

执行：校验 v2 基线与当前12核心文件一致；补齐许可证归属和公共文档；保留式增加 release 检查器与可复现打包工具，行为先写失败测试；定义最小权限CI；最终ZIP独立解压并完成回归/示例/Skill与工具层验收。源码与运行分开，本机详细日志在包外保存。

非目标：不自动推送 GitHub，不复制第三方专有宿主，不导入个人账号或会话，不宣称云端CI或目标机Agent已通过。0.1.0是首次公开整理版本，不把私有部署版v2当成公共2.0产品承诺。
