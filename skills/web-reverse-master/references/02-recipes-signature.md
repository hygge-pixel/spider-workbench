# 通用参数与协议复现

本框架不携带旧站点算法实现或采集记录。已定位的签名/加密任务交给 `param-encryptor`，环境依赖交给 `env-patcher`，混淆交给 `ast-deobfuscation`。

## 最小证据合同

1. 为多个不同输入保留脱敏样本、编码、参数顺序、时间/随机源的供应方式，以及本次观察的输出。
2. 先写样本对拍测试，再实现最小转换；逐字节定位第一次差异，不从输出长度猜算法。
3. 参数算法匹配之后，用本地新请求验证目标业务数据、字段与分页变化。签名函数能输出字符串不代表业务成功。
4. 请求上下文与会话必须同范围、可供应；Cookie/Token 只留本机允许位置，不进入样本包或日志。
5. WASM、Protobuf/gRPC、WebSocket 等先建立边界与结构，再写解析或重放；工具成功不证明目标接受。
6. 输出记录实现版本、输入合同、对拍范围、未覆盖参数和真实请求验收结果。

辅助证据脚本见本 Skill `scripts/`，使用前读各自 `--help`；不得把通用脚本当成已经实现的网站 collector。
