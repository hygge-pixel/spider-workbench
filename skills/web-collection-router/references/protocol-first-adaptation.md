# 协议优先逆向与采集：参考文档适配

## 优先级与边界

所有路线都是当次证据下的优先级，不是永久锁。配置中的浏览器、MCP、纯算法、Node.js 补环境、Python/Node HTTP、官方资料、开源实现、App 接口和浏览器补采均是候选；不要求每次经过全部候选或全部阶段。优先级可以随当前成功、失败、覆盖范围和会话状态调整。

网页首次评估优先本地浏览器/MCP 侦察；已有当前可复用、已对拍的协议证据时直接协议执行。浏览器不可用仍可依据已有成功请求做最小本地重放，记录未完成的侦察；不因首选工具失败就放弃任务。列表、明细、附件分别选路，浏览器只补本次协议不能覆盖的部分。

调整路线不放宽授权范围、数据语义、凭据保护、真实验证码暂停或完整性验收。这些是边界条件，不是工具路线锁。

## 先重放，再决定是否逆向

1. 明确采集字段、数量/时间范围、数据面、完成条件和授权；复用已有用户授权，不为每个常规阶段重复索要确认。
2. 从一个浏览器成功请求倒推 URL、Method、原始参数/Body、响应字段、发起者、分页、Cookie/Token 和前置请求。需要 Hook 时优先在初始化前注入，记录 Hook 开/关及源码版本；不擅自刷新用户页面或启用全量日志。
3. 用本地 Python/Node HTTP 做最小本地重放并逐步缩减请求依赖。XHR/Fetch 不等于加密；先排除会话失效、序列化、游标、时间戳、缓存和传输差异，再定位真正阻碍重放的动态参数。
4. 已知算法交 `param-encryptor`；未知入口交 `web-reverse-master`；混淆交 `ast-deobfuscation`；原 JS 缺运行环境交 `env-patcher`。能可靠纯算还原时优先纯算；需要原 JS 才补实际依赖。requests 不执行 JS，Python collector 可通过本地 Node 模块生成参数或发 HTTP。
5. 对多个固定输入做算法对拍，必要时控制随机数/时间；再本地生成不同页码、关键词或 Body 的新请求，确认服务端接受并返回对应业务数据。记录脱敏 `protocol_parity.json`，分数据面填写 `protocol_ready`。复制一次旧签名、返回一个字符串、HTTP 200 或请求格式正确均不足以证明持续采集。

## 动态候选与断点

浏览器、逆向与 HTTP 的推荐顺序可以被当前证据调整；无需为了“按文档走完”重复启动浏览器、搜索资料或还原已经验证的参数。网络资料用于线索补充，官方文档、开源实现和同一授权数据范围的 App/小程序接口都须核验当前版本、字段与真实样本。

普通候选失败先保存脱敏状态码/错误类别、已有记录、唯一键和 `checkpoint`，再尝试已经实现、已经授权、数据语义等价的有界候选。新路线成功后，其证据可以提高后续优先级；原路线恢复时也可以重新考虑。不能把教程的 A/B/C/D 编号、某个域名的历史成功或工具安装状态当作永久锁。

同一候选内保持会话、源码、请求 ID 与 Hook 上下文一致。切到另一个浏览器上下文时重新建立该上下文的状态，不能混用 Cookies、Storage、断点或取证结果。收到真实验证码时暂停整个运行并记录 `captcha_user_instruction_required`；只有本次运行明确指示才可追加一次性 `--allow-captcha`，不能通过切换路线绕过暂停。

## 浏览器补采与运行证据

只有保存本次协议失败或覆盖不足证据，才对该数据面启用浏览器补采。在 `collector_result.json` 写实际 route/backend、`browser_fallback_reason`、`browser_only_parts` 和脱敏协议尝试。其他已覆盖的数据面继续协议请求。

浏览器中的 fetch/context.request 不等于脱离浏览器的协议能力。工具返回成功、导出一个 Node 包、签名样本匹配、服务端接受、目标数据完整是不同的验收层级，不能互相替代。

协议批量应有限速、有界重试、会话刷新和断点；`spider.py run` 保持唯一 collector 执行入口。列表、正文、附件分别核对唯一键、原文、分页覆盖、服务端总数/源耗尽、重复、失败与成功率，不能证明全量时标记 sample/partial/unknown。

## 将老师文档用于方法参考

保留从流量倒推代码、初始化前 Hook、调用链定位、最小补环境和多输入对拍。原文的固定搜索起点、强制完整 Phase 流水线、浏览器全禁、坚持单一路线、请求格式即验收、删除测试或固定另一工作区路径不作为本项目规则。

Plan 应记录接口、字段生成/绑定、证据版本、候选、限制和完成条件；已经授权的常规实施连续推进，确需新增授权或用户输入时才停。测试与必要脱敏证据保留，不能自动清理。调试结束释放工具控制与自建页面，不擅自关闭用户手动打开的浏览器。

工具名与参数以本次暴露的 schema 为准，缺失工具只记录缺口；MCP 的 Hook/VM/WASM 能力需本次产物验证，不能根据浏览器名称宣称全部启用。不要复制其他项目的账号、API Key、Profile、端口或启动脚本。

凭据仍只允许进程环境或忽略的 `config/local_credentials/*.env`；Cookie/Token/Authorization 会话状态只留浏览器、内存或 `runs/` 树内 `cookies.json`。参考文档、Plan、日志和可提交证据必须脱敏。
